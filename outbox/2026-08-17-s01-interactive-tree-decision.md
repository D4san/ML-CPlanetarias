# Decisión de diseño: árbol interactivo central para S01

El gráfico `Excalidraw/mapa machine learning.excalidraw.md` se conserva como referencia conceptual y diagnóstico del mapa inicial. No se copiará ni se renderizará directamente en la página.

La experiencia web de S01 se diseñará alrededor de una reconstrucción original que permita:

- construir el árbol por capas;
- entrar y salir de nodos sin perder el contexto;
- consultar definición, ejemplo, misconcepción, conexiones y límites;
- seguir rutas de microproblemas astronómicos;
- reparar la mezcla entre paradigma, tarea y familia de modelo;
- usar teclado, móvil y movimiento reducido.

La ficha de interacción delimita una primera versión conceptual: no incluye datasets, entrenamiento, recomendación automática de algoritmos ni evidencia científica.
