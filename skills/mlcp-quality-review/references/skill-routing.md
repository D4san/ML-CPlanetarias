# Enrutamiento de skills del proyecto

| Necesidad | Skill principal | Entrega que debe producir |
| --- | --- | --- |
| Organizar una sesión desde `inbox/` | `mlcp-session-authoring` | paquete con inventario, secuencia, fuentes y lagunas |
| Investigar un caso o definición | `mlcp-example-research` | ficha por unidad y auditoría de afirmaciones |
| Producir o revisar un recurso visual | `mlcp-visual-assets` | ficha/manifiesto con tipo, alt, procedencia y derechos |
| Construir o cambiar la web | `develop-mlcp-web` | implementación, gates y revisión de subruta |
| Auditar cualquiera de las anteriores | `mlcp-quality-review` | matriz independiente y decisión de aceptación |

La skill de revisión acompaña la entrega; no reemplaza la skill de autoría, investigación, assets
o web que conoce el contexto de producción. Si una tarea combina capas, registra qué skill aportó
cada artefacto.
