## Lista de tareas

- [ ] Integrar exclusivamente versiones revisadas conforme A03. Si falta autoridad editorial, completar fixtures/representación de revisión y registrar qué paquete impide la promoción; no falsear estado para cerrar.
- [ ] Conectar Ver ejemplo en cada unidad explicativa, incluidas definiciones y explicaciones de actividades. Reutilizar ejemplos por ID sin duplicar fichas.
- [ ] Enlazar términos técnicos del inventario al glosario en su contexto. Evitar botones anidados y exceso de enlaces repetidos; la definición completa debe seguir accesible.
- [ ] Colocar precauciones junto a las distinciones delicadas y preguntas docentes pertinentes por unidad. Revisar que desactivar ayudas no elimine límites esenciales.
- [ ] Integrar assets con alt/pie y medir layout. Comprobar las tres rutas y actualizar todos los elementos del flujo al cambiar de caso.
- [ ] Auditar texto, imágenes, datos de tarjetas y actividades para eliminar ejemplos galácticos y concretar los genéricos. Añadir validación estructural de cobertura sobre inventario real; no usar un contador de botones como única prueba.

## Criterios de aceptación

- [ ] F04-AC1: Todas las unidades explicativas tienen ejemplo funcional, fuente pertinente y límite; el inventario no conserva lagunas requeridas.
- [ ] F04-AC2: Los conceptos enlazados resuelven definiciones sintéticas coherentes y relaciones inversas correctas.
- [ ] F04-AC3: Las tres rutas muestran ejemplos consistentes en todos los nodos de Instancia y respetan rutas deshabilitadas.
- [ ] F04-AC4: La auditoría de dominios abarca texto, alt, pies, tarjetas y actividades; cualquier mención histórica ajena a ejemplos se distingue en el informe.
- [ ] F04-AC5: Estado editorial, fuente, derechos y accesibilidad están documentados por recurso integrado.
