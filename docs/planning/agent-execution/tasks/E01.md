## Lista de tareas

- [ ] Asignar un ID a cada unidad explicativa de las siete estaciones y actividades. Incluir definiciones de tarjetas, explicaciones tras responder y subslides; no contar cada párrafo como unidad nueva.
- [ ] Mapear contenido viejo a nueva ubicación sin perder definiciones ni límites. Para cada estación declarar subslides y la razón de su orden. Usar el panel derecho como apertura salvo excepción razonada.
- [ ] Por unidad registrar idea central, objeto visual, ruta(s), conceptos, ejemplos requeridos, precaución si aplica y pregunta docente. Marcar lo que ya existe y lo que necesita F01/F03.
- [ ] Auditar bibliografía inicial: obra, edición/año, capítulo cuando esté comprobado y función didáctica. Registrar cualquier duda de atribución para investigación.
- [ ] Definir cobertura editorial completa: número real de unidades por estación, IDs de ejemplo y conceptos requeridos. Entregar lotes de tareas de investigación y assets priorizados por necesidad pedagógica.

## Criterios de aceptación

- [ ] E01-AC1: Las siete estaciones y las actividades tienen un inventario con IDs únicos y trazabilidad al contenido actual.
- [ ] E01-AC2: Todas las unidades explicativas tienen ejemplo asignado o necesidad de investigación explícita; las pendientes no se marcan cubiertas.
- [ ] E01-AC3: El orden de cada estación está decidido antes de programar; las excepciones al panel derecho primero tienen explicación.
- [ ] E01-AC4: El inventario identifica contenido galáctico o genérico a sustituir, sin asumir que ya se eliminó de todo el curso.
