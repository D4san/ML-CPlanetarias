## Lista de tareas

- [ ] Crear la plantilla de ejemplo definida en CONTRACTS: pregunta, dominio, datos/representación, tarea, baseline cuando aplique, salida, evaluación, interpretación, límite, fuente y afirmación respaldada.
- [ ] Separar el ID del ejemplo de la URL del recurso y del ID del asset. Una fuente puede respaldar varios ejemplos; una noticia contextual no se registra como prueba del método.
- [ ] Migrar a fichas los ejemplos existentes de Pregunta e Instancia como ejemplos didácticos, conservando el estado de evidencia real. No buscar todavía fuentes para todo S01: F01 se encarga.
- [ ] Crear el registro consultable por ID y la validación de enlaces entre unidad y ejemplo según el esquema B01. Enlazar el inventario editorial sin duplicar manuscritos privados.
- [ ] Dar al componente C03 fixtures de un ejemplo con paper, otro con página institucional y otro conceptual pendiente de fuente que no pueda pasar la promoción editorial.

## Criterios de aceptación

- [ ] C01-AC1: Cada ficha distingue ejemplo didáctico, evidencia de fuente y figura; ningún recurso sin verificar aparece como validado.
- [ ] C01-AC2: Los casos nuevos pertenecen a exoplanetas; una alternativa estelar incluye justificación; no se incorporan galaxias.
- [ ] C01-AC3: No hay referencias huérfanas ni IDs duplicados; un recurso pendiente bloquea su promoción, no se sustituye por un enlace inventado.
- [ ] C01-AC4: La plantilla sirve para crear un ejemplo sin editar el componente visual.
