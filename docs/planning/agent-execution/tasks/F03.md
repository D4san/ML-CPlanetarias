# F03 · Producir y revisar los recursos visuales necesarios

Estado inicial: pendiente. Fase: 5 · Fuentes e imágenes. Responsable sugerido: Agente de recursos visuales.

- Requisitos: R10,R11,R16.
- Dependencias aceptadas: F01, F02.
- Lectura común obligatoria: [README](../README.md), [contratos](../CONTRACTS.md) y [validación](../VALIDATION.md).

## Entradas

Cola de assets F01; guía F02; skill mlcp-visual-assets y skill imagegen; fuentes y derechos por recurso.

## Archivos permitidos y entrega

Recursos en carpeta de assets fijada por A02, manifiestos y previews; evidence/F03.md. El integrador decide cuáles ingresan a rutas públicas tras revisión.

Las rutas son relativas a la raíz del repositorio. Los nombres nuevos son destinos propuestos que A02 fija antes de implementarlos. Pedir al integrador una reasignación si aparece una necesidad fuera de esta lista; continuar con lo independiente.

## Lista de tareas

- [ ] Seleccionar primero las unidades cuyo concepto depende de reconocer un objeto/flujo; dar prioridad a Instancia. Mantener esquemas actuales correctos cuando ya satisfagan la necesidad.
- [ ] Crear un lote acotado por caso/ruta. Usar la herramienta GPT para ilustraciones acordadas, SVG/HTML para relaciones y etiquetas exactas, y código para gráficos cuantitativos.
- [ ] Inspeccionar cada resultado a escala de uso y móvil. Verificar identidad del objeto a lo largo del flujo, dirección de flechas, correspondencia con el texto y ausencia de números/etiquetas ficticios.
- [ ] Corregir los recursos que fallen; conservar trazabilidad de qué versión quedó aceptada. Generar alt y pie con la distinción conceptual/simulado/observado.
- [ ] Optimizar formato/tamaño conforme F02, documentar dimensiones intrínsecas y evitar saltos de layout. Registrar manifestación de derechos y procedencia.
- [ ] Entregar contactos o vistas de revisión con la unidad y el caso identificados; un archivo generado no se declara integrado hasta F04.

## Criterios de aceptación

- [ ] F03-AC1: Cada asset entregado resuelve una necesidad del inventario y supera inspección pedagógica, visual y científica.
- [ ] F03-AC2: La serie de Instancia permite reconocer el mismo caso en observación, representación, modelo y salida.
- [ ] F03-AC3: Alt, pie, dimensiones y procedencia están completos; no se presentan ilustraciones GPT como datos observados.
- [ ] F03-AC4: No quedan recursos que excedan el presupuesto sin excepción justificada ni etiquetas ilegibles al tamaño final.

## Evidencia y validación

Manifiesto por asset, previews desktop/móvil, lista de correcciones y aceptación individual.

Aplicar los gates proporcionales de VALIDATION.md. Completar [el informe de entrega](../templates/DELIVERY.md); marcar un criterio solo con evidencia. El agente propone entrega; el revisor acepta la tarea en BOARD.md.

## Criterio de logro

F04 puede incorporar recursos ya revisados mediante IDs sin reinterpretar su significado.

## Límites de esta tarea

No generar por volumen ni reutilizar figuras de terceros con derechos inciertos; si falta herramienta registrar assets afectados y avanzar con fichas/esquemas apropiados.
