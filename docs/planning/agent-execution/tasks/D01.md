# D01 · Crear la skill de preparación de sesiones

Estado inicial: pendiente. Fase: 3 · Skills. Responsable sugerido: Agente de skills pedagógicas.

- Requisitos: R01,R02,R06–R08,R12,R14–R16.
- Dependencias aceptadas: A02, A03.
- Lectura común obligatoria: [README](../README.md), [contratos](../CONTRACTS.md) y [validación](../VALIDATION.md).

## Entradas

Skill skill-creator disponible en el entorno del ejecutor; skills/develop-mlcp-web/SKILL.md; contrato A02; política A03; este plan.

## Archivos permitidos y entrega

skills/mlcp-session-authoring/SKILL.md y recursos mínimos; evidence/D01.md. No editar espejos ni scripts compartidos; D04 los integra.

Las rutas son relativas a la raíz del repositorio. Los nombres nuevos son destinos propuestos que A02 fija antes de implementarlos. Pedir al integrador una reasignación si aparece una necesidad fuera de esta lista; continuar con lo independiente.

## Lista de tareas

- [ ] Leer skill-creator antes de crear la skill. Mantener instrucciones breves en SKILL.md y llevar plantillas detalladas a referencias; declarar disparadores y salidas concretas.
- [ ] Enseñar el flujo paquete → inventario → bibliografía → secuencia → ejemplos/conceptos → preguntas/precauciones → revisión. Incluir la jerarquía curso/sesión/estación/unidad y IDs del contrato.
- [ ] Crear plantilla de sesión, plantilla de unidad y checklist de cobertura. Una unidad expresa pregunta, objeto visual, idea central, interpretación, ejemplo, conceptos y límites.
- [ ] Incluir cómo trabajar con lagunas de fuente: marcar pendiente, formular una tarea de investigación y no rellenar con citas inventadas. Conservar origen y frontera de publicación.
- [ ] Probar la skill sobre un fragmento ya existente de Pregunta/Instancia; producir un borrador de ejemplo fuera del build y registrar dónde la instrucción resultó ambigua.

## Criterios de aceptación

- [ ] D01-AC1: La skill permite producir un paquete válido sin editar componentes ni duplicar el protocolo web.
- [ ] D01-AC2: Incluye pasos y plantilla de salida, ejemplo completado y errores frecuentes con acciones de reparación.
- [ ] D01-AC3: La prueba conserva bibliografía y vínculos de ejemplo/concepto y señala lagunas reales.
- [ ] D01-AC4: No promete capacidad de validar ciencia/publicación de forma automática ni requiere leer todo el repositorio.

## Evidencia y validación

Validación indicada por skill-creator si está disponible, checklist manual equivalente si no; prueba de uso con entrada/salida y límites.

Aplicar los gates proporcionales de VALIDATION.md. Completar [el informe de entrega](../templates/DELIVERY.md); marcar un criterio solo con evidencia. El agente propone entrega; el revisor acepta la tarea en BOARD.md.

## Criterio de logro

Otro agente puede preparar una sesión con el contrato actual usando solo las lecturas indicadas.

## Límites de esta tarea

No crear automáticamente tareas/agentes ni publicar el paquete de prueba.
