## Resultado

`DomainScene` separa `apertura`, `cambio`, `diagnostico`, con hashes `#dominio`, `#dominio/cambio` y
`#dominio/diagnostico`. La gráfica distingue señal latente, serie sintética, medición observada,
incertidumbre y cobertura faltante; los controles permiten comparar condiciones antes de transferir
el modelo.
