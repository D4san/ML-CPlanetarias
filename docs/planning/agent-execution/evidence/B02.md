# Evidencia B02 · Extracción de navegación y escenas de S01

Estado propuesto: aceptada.  
Responsable/revisor: Codex integrador. Fecha: 2026-09-08.  
Dependencias usadas: A02 y los contratos vigentes de `SlideRail`.

## Resultado

`S01LearningJourney` conserva el estado único de ruta, estación, parte, vista y tarjetas, y delega
la presentación a módulos independientes. `SceneForStop` selecciona la escena; `S01Pilot` conserva
el contexto de configuración; `S01Navigation` y `s01-slides.ts` mantienen el carril transversal.
Las siete estaciones tienen interfaces explícitas y cada una puede mostrar apertura, figura o
interacción como una sola superficie principal.

| Criterio | Resultado | Evidencia concreta |

estado del recorrido.
