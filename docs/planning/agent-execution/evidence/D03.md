## Ensayo con recurso existente

### Ficha completada

- `id`: `d03-ensayo-reglas-aprendizaje`
- `session_station_unit`: `S01 / actividades / reglas o aprendizaje`
- `case`: una curva de luz que abre una ruta de reglas explícitas y otra de aprendizaje desde ejemplos
- `purpose`: hacer visible la diferencia entre codificar reglas y ajustar desde ejemplos etiquetados

- `visible_relation`: señal inicial → ruta de umbrales explícitos o conjunto de ejemplos → salida de modelo

- `type`: `conceptual`
- `exact_payload`: ninguno dentro de la imagen; las etiquetas críticas deben ir en HTML/caption, y cualquier gráfica numérica debe migrar a SVG/HTML o código reproducible
- `deliberate_omissions`: números, ejes, unidades, ecuaciones, nombres de modelos y afirmaciones de medición
- `style_reference`: `docs/protocols/VISUAL_SYSTEM.md` y los roles de `src/styles/tokens.css`

- `review_return_condition`: devolver si se usa como dato, si la distinción depende solo del color, si el contexto pierde el caption/alt o si falta el manifiesto durable
