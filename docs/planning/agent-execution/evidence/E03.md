# Evidencia E03 · Tarea y salida

Estado propuesto: aceptada.  
Responsable/revisor: Codex integrador. Fecha: 2026-09-08.  
Dependencias usadas: E01, B02 y B03.

## Resultado

`TaskScene` separa `apertura`, `salidas` y `niveles`, con hashes `#tarea`, `#tarea/salidas` y
`#tarea/niveles`. `TaskAlgorithmTree` conserva seis ramas y sus definiciones; `TaskLevelsGuide`
explicita señal → tarea → familia. La interfaz mantiene la distinción entre la forma de salida y
el algoritmo.

## Aceptación

| Criterio | Resultado | Evidencia concreta |
| --- | --- | --- |
| E03-AC1 | aprobado | IDs `s01-task-opening`, `s01-task-tree`, `s01-task-levels` coinciden con `s01Parts` y la ficha específica. |
| E03-AC2 | aprobado | La ruta activa resalta ramas y niveles desde el estado del contenedor; las tarjetas directas y los diálogos interactivos comparten definiciones. |
| E03-AC3 | aprobado | Proyección 1920×1080 y móvil 390×844 pasan para las tres partes; el árbol compacto conserva sus seis salidas sin recorte principal. |
| E03-AC4 | aprobado | Seis botones de tarea tienen nombres accesibles, devuelven foco al cerrar y pasan axe/movimiento reducido. |
| E03-AC5 | aprobado | El inventario ubica tarea, árbol y niveles; la ficha deja ejemplos externos y baseline para F01/F04. |

Criterio de logro: cumplido. La salida se puede discutir antes de seleccionar una familia de
modelos.
