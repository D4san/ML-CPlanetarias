# Evidencia B03 · Configuración del fork

Estado propuesto: aceptada.  
Responsable/revisor: Codex integrador. Fecha: 2026-09-08.  
Dependencias usadas: B01, A02 y A03.

## Resultado

El fork usa `config/course.config.ts` con identidad, defaults, `enabledSessionIds` y configuración
por sesión. `defineCourseConfig` normaliza V2 y conserva un adaptador temporal para la forma legacy;
`resolveSessionSettings` aplica la precedencia de sesión definida → curso → default, incluyendo
`false` explícito.
