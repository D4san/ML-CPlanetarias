## Ensayo con S01

Entrada utilizada:

- `inbox/sessions/S01-ML-IA-metodos-estadisticos/SESSION_PACKET.md`: `Apertura que debe conservarse`, `0. Apertura: qué intentamos responder cuando tenemos datos` y `2. El ciclo mínimo de ML`.
- `inbox/sessions/S01-ML-IA-metodos-estadisticos/S01-SOURCE-MAP.md`: secuencia de lectura, tablas de Géron/Kelleher y regla de redacción.
- `inbox/concepts/S01-CONCEPTS.md`: semillas 1–4 y cola de atomización.
- `src/lib/s01-slides.ts`: partes vivas `question`/`instance`, incluidos `flujo` y `notacion`; se leyó para alinear IDs y no se modificó.

Salida:

- `skills/mlcp-session-authoring/references/example-s01.md`.
- Inventario de bibliografía 0, `question`, `instance` y tres unidades namespaceadas: `s01-question-opening`, `s01-instance-flow`, `s01-instance-notation`.
- Ejemplo `s01-spectrum-abundance`, conceptos provisionales enlazados por ID, pregunta de apertura y precaución `metric-no-physics`.
- Estado conservado como `drafting`, `internal`, `publish_ready: false`.

Ambigüedades registradas:

1. `apertura` se repite como parte viva de dos estaciones; la reparación fue conservar el contexto `question/*`/`instance/*` y namespacear las unidades editoriales.
2. Los encabezados narrativos no fijan una correspondencia uno-a-uno con todas las partes de Pregunta/Instancia; `question/salidas`, `question/disciplinas` e `instance/apertura` quedaron explícitamente fuera del fragmento.
3. “Abundancia” no fija escala del objetivo, etiquetas ni métrica; el ejemplo deja la regresión condicional y retiene esa decisión para una práctica posterior.
4. Las referencias recibidas están a nivel de capítulo; la ubicación exacta por afirmación quedó pendiente. La definición amplia de IA/estadística requiere bibliografía específica adicional.
5. El fragmento describe esquemas, pero no trae un registro completo de asset; el archivo, alt, pie, procedencia y derechos quedan como tarea posterior.

Durante el primer chequeo de invariantes se buscó la etiqueta `ubicación pendiente`, que no aparecía literalmente aunque la laguna estaba descrita. Se corrigió a `ubicación exacta pendiente` y el ensayo final pasó. Esta corrección quedó incorporada en `example-s01.md`.
