## Verificación matemática

| Caso | Conteos / pesos | Gini antes → ponderado / reducción | Entropía antes → ponderada / ganancia |
| --- | --- | --- | --- |
| Nodo puro | proporciones 1 y 0 | 0 | 0 bits, con `0 log₂ 0 = 0` |
| Mezcla equilibrada | 4 y 4; proporciones 1/2 y 1/2 | 0,5 | 1 bit |
| Corte 1,3 R⊕ | izquierda 3/0; derecha 1/4; pesos 3/8 y 5/8 | derecha 0,32; 0,5 → 0,2 / 0,3 | derecha 0,721928; 1 → 0,451205 / 0,548795 bits |
| Corte perfecto 1,5 R⊕ | ramas 4/0 y 0/4; pesos 1/2 y 1/2 | 0,5 → 0 / 0,5 | 1 → 0 / 1 bit |

Las pruebas conservan conteos y pesos en todos los cortes candidatos. En regresión, corte raíz 2,5 da SSE 365,5 y MSE 60,9167; raíz 3,5 da SSE 544 y MSE 90,6667. Raíz 2,5 más segundo corte derecho 3,5 da SSE 2,5 y MSE 0,4167. Reducir el error sobre estos casos sintéticos no demuestra generalización.
