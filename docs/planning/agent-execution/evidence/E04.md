# Evidencia E04 · Familia y aprendizaje

Estado propuesto: aceptada.  
Responsable/revisor: Codex integrador. Fecha: 2026-09-08.  
Dependencias usadas: E01, B02 y B03.

## Resultado

`FamilyScene` separa `apertura`, `reglas`, `sesgo`, con hashes `#familia`, `#familia/reglas` y
`#familia/sesgo`. La comparación entre reglas explícitas y aprendizaje desde ejemplos conserva
su control; el mapa de familia cerrada/abierta y el caso híbrido hacen visible el sesgo inductivo.

## Defectos y límites

- El mapa demuestra el espacio de hipótesis de una muestra finita; no afirma que una familia tenga
  mejor desempeño sin baseline y evaluación.
- El modo `rules` permanece separado de las actividades y no registra resolución automática.
