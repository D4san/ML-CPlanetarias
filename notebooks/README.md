# Notebooks

Prácticas reproducibles del curso. Cada notebook debe declarar la pregunta de aprendizaje, los datos y su procedencia, el entorno requerido y los límites de interpretación. Si usa aleatoriedad, fija una semilla. Si entrena o compara modelos, declara línea base y métrica pertinentes; un ejemplo conceptual puede usar un criterio de observación más simple. Sigue el [protocolo para código pedagógico](../docs/protocols/PEDAGOGICAL_CODE.md).

El `.ipynb` versionado en este repositorio es la versión fuente del curso. La página de la sesión puede ofrecer **Abrir en Colab** cuando el notebook se haya probado desde un entorno limpio. Se indica al estudiante cómo guardar una copia personal, por defecto en Drive; esa copia no reemplaza el archivo fuente.

Un notebook no se publica por estar en esta carpeta.
