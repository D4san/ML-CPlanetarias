# Recursos visuales de S01

El gráfico inicial de ML vive en el vault como:

```text
Excalidraw/mapa machine learning.excalidraw.md
```

No se copia automáticamente al repo ni se presenta completo como conocimiento previo. Es un mapa bastante desarrollado de métodos, tareas, arquitecturas y referencias; puede funcionar como panorama del terreno después de una primera situación astronómica. La clase debe añadirle una lectura progresiva y una cadena de decisión que el grupo pueda seguir.

La referencia contiene `Machine Learning` como raíz y reúne aprendizaje supervisado, no supervisado, regresión, clasificación, clustering, redes neuronales, deep learning y ejemplos de aplicaciones. La experiencia web conservará esos términos, pero los mostrará por capas: panorama inicial, construcción del tablero, clasificación conceptual y enlaces a referencias. El mapa no se descarta; se convierte en uno de los estados del material.

El gráfico corregido debe mostrar, como mínimo:

```text
señal/paradigma → tarea/salida → familia de modelo → entrenamiento → evaluación
```

También debe indicar que deep learning no es un cuarto paradigma y que batch/online e instance/model-based son ejes distintos.

La interacción acordada debe permitir construir el árbol por capas, entrar en cada nodo, conservar contexto mediante minimapa y migas, seguir rutas de microproblemas astronómicos y volver al panorama. Su contrato vive en `docs/specs/interactions/s01-interactive-learning-tree.md`.

La producción debe conservar también el proceso de la clase: capturas o transcripciones de las etapas del tablero, decisiones de agrupación, preguntas que hicieron aparecer cada distinción y versión final depurada.

El Excalidraw permanece en el vault privado. No se exporta ni se publica sin una decisión separada de procedencia y derechos.
