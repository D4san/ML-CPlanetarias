# Inbox de aterrizaje

`inbox/` recibe paquetes detallados desde Obsidian. Es una zona de trabajo y revisión, no la página web final.

## Qué puede contener un paquete

- explicación teórica propia;
- ecuaciones y supuestos;
- guion o estructura de una sesión;
- gráficos originales o instrucciones para reconstruirlos;
- preguntas astronómicas acotadas;
- referencias bibliográficas y procedencia;
- criterios para convertir el material en `docs/`, `notebooks/`, `exercises/` o `glossary/`.

## Qué no debe entrar

- libros completos o extracciones integrales;
- datos privados o sin autorización de redistribución;
- credenciales;
- archivos que se pretendan publicar sin revisión;
- copias sin `source_note`.

## Cómo crear un paquete

1. Copiar `_template-packet.md` a una carpeta con identificador estable.
2. Completar el frontmatter y las referencias a Obsidian.
3. Añadir el contenido propio y los recursos originales.
4. Registrar el paquete en `INDEX.md`.
5. Mantener `status: intake` hasta revisar alcance, fuentes y visibilidad.
